# Scientific Calculator Using C Language

## Description
The Scientific Calculator is a mini project developed using the C programming language that performs both basic and advanced mathematical operations. Unlike a simple calculator, this program handles scientific computations such as trigonometric functions, logarithms, exponentiation, and square roots.

The main objective of this project is to apply programming concepts like functions, loops, conditional statements, and switch cases to create an efficient and user-friendly calculator. The program takes input from the user through the console and performs calculations based on the selected operation.

This calculator supports operations such as addition, subtraction, multiplication, division, power calculation, square root, sine, cosine, tangent, and logarithmic functions. It uses standard libraries like `math.h` to perform complex mathematical calculations.

The project helps improve problem-solving skills and understanding of modular programming in C. It also demonstrates how real-world applications like calculators can be implemented using basic programming techniques.

## Key Features
- Performs basic arithmetic operations  
- Supports scientific functions (sin, cos, tan, log, sqrt, power)  
- User-friendly menu-driven interface  
- Error handling (e.g., division by zero)  
- Uses functions for better code structure  

## Tools & Technologies Used
- Programming Language: C  
- Compiler: GCC / Turbo C  
- Libraries: `stdio.h`, `math.h`  

## Conclusion
This project demonstrates the practical implementation of C programming concepts in developing a useful application. It serves as a foundation for building more advanced calculators or GUI-based applications in the future.
